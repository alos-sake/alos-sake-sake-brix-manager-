# 日本酒 糖度測定・スペック管理 V2

Streamlit + Neon PostgreSQL を使う、日本酒の実測値・酒質スペック管理アプリです。新しいプロジェクトとして作成し、旧アプリを直接変更せずに検証してから切り替える前提です。

## この版の主な機能

- 糖度の個別実測値 `m1`〜`m6` を保存。平均・最大・最小・範囲・中央値・標準偏差は自動計算・表示しません。
- 糖度入力は6回分をコンパクトな直接入力行で表示し、選択した1枠だけを編集する共通ドラムロールを使います。スマホでは数字キーボードと上下スワイプ、PCではキーボード入力と矢印キーに対応し、0.01 °Bx刻みで記録します。
- アルコール度数、日本酒度、酸度、アミノ酸度、精米歩合は、保存対象チェックを入れて値を入力した項目だけを保存します。未入力と0を区別します。
- 銘柄名・商品名の読み仮名を保存し、ひらがな・カタカナ・漢字や別名で登録済みデータを検索できます。読みの自動推測は確定扱いにせず、利用者による確認状態を記録します。
- 登録済みDB検索は即時実行し、外部AI検索とは分離しています。外部AI検索は `GEMINI_SEARCH_MODEL`（初期値 `gemini-2.5-flash`）でGoogle Search groundingを使います。Gemini 2.5 Flashは[公式料金表](https://ai.google.dev/gemini-api/docs/pricing)上、無料枠でGoogle検索グラウンディングに対応し、最大500リクエスト/日とされています（共有枠・アカウントごとの実際のクォータは要確認）。検索結果は7日間キャッシュします。
- 選択できる情報源：
  - 勝鬨酒販
  - はせがわ酒店
  - いまでや酒店
  - 山中酒の店（大阪）
  - 住吉酒販
  - 登酒店
  - 佐野屋 JIZAKE.COM
  - 酒専門店鍵や
  - 矢島酒店
  - マツザキ
  - さけのわ、さけのわ公開データ、SAKEOpenData、日本酒スペック公開データセット、酒蔵公式サイト、その他のウェブ検索
- AI外部検索は1回最大3情報源、HTTPタイムアウト15秒、再試行なしです。検索先が多すぎることによる待ち時間や無駄なリクエストを抑えます。タイムアウトの厳密な総処理時間保証ではありません。検索結果は7日間キャッシュします。
- 情報源別の直接検索リンクはクエリ文字列から即時生成し、Gemini APIを呼び出しません。商品ページはブラウザーで直接開いて確認できます。直接検索リンクは商品情報を自動取得した結果ではありません。
- JSONバックアップのダウンロードと復元、登録データの検索・編集・削除、選択記録の比較。
- 旧バージョンのJSONを取り込む際、旧「代表糖度・集計値」は `legacy_data` に参考情報として残し、実測値 `m1`〜`m6` に勝手に変換しません。

## データベースと秘密情報

データベースは Neon PostgreSQL を使います。**GitHub リポジトリにDB接続URL、パスワード、Gemini APIキー、実際の測定データをコミットしないでください。**

Streamlit Community Cloud のアプリ設定画面で `Settings` → `Secrets` を開き、次を設定します。

```toml
DATABASE_URL = "Neonの接続文字列"
GEMINI_API_KEY = "Gemini APIキー"
GEMINI_MODEL = "gemini-3.8-flash"
GEMINI_SEARCH_MODEL = "gemini-2.5-flash"
```

`DATABASE_URL` は必須です。`GEMINI_API_KEY` は登録済みデータの手入力・閲覧や直接検索リンクには必須ではありませんが、AI外部検索とラベル画像解析に必要です。`GEMINI_MODEL` はラベル解析、`GEMINI_SEARCH_MODEL` は外部検索で別々に使います。接続文字列とキーをチャットやGitHubのソースコードに貼らないでください。

Neonでプロジェクトを作成し、Connect画面の接続文字列を使用してください。Streamlitの実行環境からアクセスする接続文字列を選び、必要な場合はNeonの推奨するプール接続を利用します。

## Streamlit Community Cloud でのデプロイ

1. GitHubの新しいPrivateリポジトリへ上記ファイルをコミットします。
2. Streamlit Community Cloudで `Create app` を選びます。
3. Repositoryを新しいリポジトリ、Branchを `main`、Main file pathを `app.py` にします。
4. Advanced settings またはアプリのSettingsから `DATABASE_URL` と必要なGemini設定をSecretsへ登録します。
5. Deploy後に、空DBで新しいテーブルが作成されること、テスト記録を保存・検索・削除できることを確認します。

初回起動時に `measurements` と `sake_search_cache` テーブル、および必要なインデックスを作成します。テーブル作成に失敗した場合、アプリは接続エラーを表示します。

## ローカル実行

Python 3.11以上を推奨します。

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
# source .venv/bin/activate
python -m pip install -r requirements.txt
```

ローカルの `.streamlit/secrets.toml`（`.gitignore` 対象）に同じ設定を記載するか、環境変数 `DATABASE_URL` を設定してから起動します。

```bash
streamlit run app.py
```

python -m py_compile app.py db.py data_model.py search_sources.py test_data_model.py test_db_contract.py test_search_sources.py test_ui_input_contract.py test_ui_input_contract.py

テストは入力検証、ひらがな正規化、レガシーデータの保持、情報源ドメイン照合、SQL列・プレースホルダー数などを検証します。実際のNeonプロジェクト、Gemini API、StreamlitのブラウザーUIを自動テストだけで検証するものではありません。初回公開後に手動の画面テストも必要です。

## 古いアプリからのデータ移行

1. 旧アプリの「JSONバックアップ」をダウンロードします。
2. ファイルを安全な場所に複製して保管します。
3. 新アプリの「バックアップ・復元」画面でJSONを選び、プレビューとエラー件数を確認します。
4. 復元を実行します。同じUUIDの記録はスキップされます。
5. 旧バージョンで糖度の代表値しか保存していなかった行は、旧値を `legacy_data` に保持します。その値を実測値 `m1`〜`m6` として扱うことはしません。
6. 移行後は件数・名称・値を確認し、別の場所にもバックアップを保管してください。

旧DBファイル自体をGitHubにアップロードしないでください。

## データの長期保全と注意事項

- Neonの無料プランの使用量・休止条件・バックアップ条件は変更される場合があります。利用開始時に最新の公式条件を確認してください。
- アプリ内でJSONバックアップを定期的にダウンロードし、GitHubとは別の安全な場所に保管してください。
- 現在の実装では登録済みの出典URL・短い項目情報を保存し、酒販店のカタログ全体を複製しません。AI外部検索はGoogle検索の結果に依存し、選んだ全サイトを毎回網羅する保証はありません。直接検索リンクはGoogleの通常検索ページを開くだけで、商品データを自動取得しません。
- 登酒店など、無許可の転載・転用を禁止しているサイトの掲載文を一括取得・転載しない方針です。スペックを反映する際も、候補・出典・実物ラベルを確認してください。
- 商品名が似ていても、年度、ロット、生酒/火入れ、容量などが異なることがあります。検索結果は候補として提示され、利用者が確認後に入力フォームへ反映します。
- 画像自体はDBに保存しません。


## コンパクトな糖度入力（直接入力＋共通ドラムロール）

- 糖度は0.00〜50.00 °Bx、小数第2位まで入力できます。平均・最大・最小・範囲・中央値・標準偏差は自動計算しません。
- 測定1〜6を小さな行で表示し、各行に空欄の直接入力欄と保存対象チェックを用意します。
- ドラムロールは1つだけ表示し、測定枠を選んで整数部・小数第1位・小数第2位を上下にスワイプして選択します。ホイールで値を確定すると、その測定枠を保存対象として自動で有効にします。
- スマートフォンの直接入力欄には `inputmode=decimal` を指定し、小数キーボードを開きやすくしています。PCではキーボード入力、クリック、上下矢印キーで操作できます。
- 新規登録では実測値 `m1`〜`m6` を個別保存し、集計用の値を作りません。
